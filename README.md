## 本单范围逐项

1. 研究对象：正和岛，以及两家章程公开可查的全国性行业协会，写明名称与章程来源 → `memo.md` 研究说明和三个对象小节。
2. 研究问题①会员分级与权利义务 → 各对象「做法」①，以及分级表。
3. 研究问题②会费与权益结构，只记分档逻辑和缴费周期 → 各对象「做法」②；分级表「会费分档」列只写逻辑。
4. 研究问题③供需对接机制（名录、对接会、资源发布、诚信或信用评价） → 各对象「做法」③，以及单列的供需对接机制一节。
5. 研究问题④入会审核与推荐人制度 → 各对象「做法」④；公开资料没有推荐人细则的，原文写明，不作推断。
6. 研究问题⑤线上平台功能清单（App、小程序、公众号） → 各对象「做法」⑤。
7. 研究问题⑥退出、除名、会员信息使用条款 → 各对象「做法」⑥，引用到章程条号或隐私政策条款。
8. 「会员分级 × 权利义务」表 → `membership_rights_matrix.md` / `.csv`。
9. 可借鉴点映射到资源对接与商机流转、会员数据中台与 CRM、微信小程序会员端 → 各对象「可借鉴点」，每条写明映射模块（Z1–Z5、C1–C5、I1–I4）。
10. 不适用点重点分析社团法人章程约束、行业主管单位指导属性 → 两家协会「不适用点」，逐条引用章程条号。
11. 备忘录五段结构，3000–5000 字 → 实测汉字 4006，按 Word 口径（汉字加标点加英文数字词）4914。
12. 交付物：研究备忘录（Markdown）、分级表、来源登记表（CSV） → `memo.md`、`membership_rights_matrix.md` / `.csv`、`sources.csv`。

## 文件

- `memo.md`：研究备忘录
- `membership_rights_matrix.md`、`membership_rights_matrix.csv`：会员分级 × 权利义务表（md 由 csv 生成，内容一致）
- `sources.csv`：来源登记表（编号、标题、发布方、链接、访问日期、用途）
- `check_sources.py`：自检脚本

## 复跑方法

需要 Python 3.9 或以上，只用标准库，不需要安装依赖：

```
python check_sources.py            # 全部检查，含逐条请求来源链接
python check_sources.py --offline  # 无网络时跳过链接检查
```

可选环境变量：`CHECK_TIMEOUT`（单条链接超时秒数，默认 30）、`CHECK_RETRIES`（失败重试次数，默认 2）。全部通过时输出 `ALL PASS` 并以 0 退出；任何一项不通过以 1 退出。

检查项：字数两种口径；三个对象五段结构和研究问题①–⑥；章程来源是否官方网站；分级表每个对象的级别数；供需机制数量及是否写明环节和字段；来源条数、访问日期、备忘录引用与登记表一致；链接实时可打开；会费金额扫描；可借鉴点覆盖三个模块；不适用点覆盖社团法人约束和主管单位指导属性。

## 约束

- 只用公开资料，不访问需要登录的页面，不做访谈，不用付费数据库。
- 不记录任何会费金额；中国软件行业协会会费办法里的示例金额没有抄录。
- 不出现客户名称；研究对象均为公开机构。
- 正和岛官网和隐私政策页需要浏览器执行脚本才显示内容，内容核对使用 Chrome 无头模式渲染；检查脚本只验证链接可打开。
- 中国软件行业协会的会费办法、会员管理办法、入会流程在官网以图片形式发布，内容为人工逐页阅读后摘录。
